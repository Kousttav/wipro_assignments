# Milestone 3
# Robot Framework Automation

---

## Introduction

Robot Framework is an open-source automation framework based on a keyword-driven testing approach.

It supports web automation, API testing, desktop automation, and acceptance testing.

---

## Objectives

- Learn Robot Framework syntax.
- Automate web applications.
- Implement Data Driven Testing.
- Create custom keywords.
- Generate reports and logs.
